# Smart Garden

Raspberry Pi voice-controlled garden. Speech recognition -> DeepSeek via OpenAI-compatible cloud API -> prompted JSON commands -> device control -> gTTS response. Includes mode/state integration.

## Snapshot status

raspberrypi is the available archived school repository snapshot. The separately supplied interface repository is pending retrieval and is NOT included yet. No claim of local model deployment. Configure secrets locally; sanitised literal credentials must be replaced before use.
